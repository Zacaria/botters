# Live matches on Lightsail

This supersedes the checkpoint/subscription architecture in `pvp-spec.md`. Historical measurements in `pvp-release.md` describe the previous deployment, not this candidate.

## Authority and transport

One Colyseus room owns each match. `sim.js` advances at 20 Hz in server memory; recipient-filtered frames go over WebSockets at 12.5 Hz. The same in-memory game accepts MCP HTTP inputs/events. Private rooms, queue, input logs, presence and reconnect state live in this process. A dropped browser reconnects to the same match; process loss interrupts unfinished matches rather than silently replaying them from Convex. Finished reports, Elo and session history survive restarts.

The website and account flows stay on Vercel. This release preserves the currently active anonymous production mode. Human and agent capabilities are separate; the live service subscribes to capability/session authorization only (never match state), fails closed on a disconnected channel, and revalidates half-open channels every 90 seconds. Expiry remains explicit. Identity is never accepted from client-supplied account IDs.

The separately gated account rollout is not activated here. Its cookie-bound human tokens are deliberately rejected by anonymous live mode; enabling account mode fails at startup until a reviewed cookie-to-live-session exchange exists. This avoids weakening the already-reviewed cookie requirement merely to cross origins. The entry action stays disabled until connection settings have loaded and its handlers are installed. Offline mode remains separate: the shared page uses the existing local SSE endpoint when its lobby does not advertise online play, without loading the Colyseus browser bundle.

Convex is used for session/capability checks and match start/end boundaries, Elo and history. Simulation ticks, frames, events and inputs do not call Convex. Boundary writes must be atomic and idempotent; failed result persistence is retried without double-rating a result. The measured release target is at most 50 Convex function calls per full eight-minute match, including authorization refreshes and persistence. Count actual adapter calls, not an extrapolated frame-rate reduction.

## Limits and verification

The existing input budgets remain five agent and fifteen human inputs per second. Live HTTP admission is 2,400 requests per minute per IP, with at most forty unknown-capability lookups per minute and twenty new sessions per ten minutes per IP. The process admits at most twenty-four rooms; that is a protective ceiling, not a measured throughput guarantee. Imported authorization caches expire, and both each frame emission and each queued mutation recheck the authorization lease. Faulted channels are closed so the next retry obtains fresh authority; generation fencing rejects late callbacks from retired channels. Authorization adoption preserves each player's process-local private-room preferences (solo/agent choice and opening gambits), including refreshes and newly opened agent channels. Those preferences are not included in peer room information. Admission rejects `/play`, `/rooms/start` and `/rooms/rematch` at the room ceiling before changing queue, readiness or membership; retrying after space frees preserves existing rematch votes. There is no common Colyseus state schema exposing the simulation.

`npm test`, `npm run check`, `npm run test:auth:convex` and `npm run test:browser` cover the canonical source. For a full timed match use `BOTTERS_SERVER=<website> BOTTERS_LIVE_SERVER=<live origin> BOTTERS_UNACCELERATED=1 npm run test:online`. The script uses two real stdio MCP clients with scripted policies, not model inference. `scripts/measure-live-capacity.js` is explicitly a stationary 80-swarm fixture; its short loopback sample does not prove sustained WAN traffic or simultaneous end-report replay capacity.

Before replacing a container, `/health` must show no active rooms. Before moving the Vercel aliases, query `store:legacyActivity` with the production prefix and a fresh `now` nonce; require `complete: true` and `activeMatches: 0`. This query returns only aggregate counts and never writes or returns player records. Never deploy Convex from the Vercel-only release branch. For protected preview checks, keep the automation bypass credential scoped to the website; it must not be forwarded to the live host. A temporary exact preview origin may be allowed while testing and removed while the service is idle.
