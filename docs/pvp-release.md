Measurement: `scripts/measure-usage.js` runs an unaccelerated five-minute/28-planet match, two isolated Brave contexts and two actual stdio MCP agents, using a local HTTP preview backed by actual free-plan Convex in a unique expiring namespace. Instrumented `ConvexStore.call` counts successful REST operations and ordered WebSocket mutations; `onWatchSnapshot` additionally counts every delivered reactive query snapshot (including initial/reconnect results). Byte counters sum UTF-8 JSON value payloads returned by those queries and supplied as CAS guards/writes. They exclude document/index metadata, authentication-component usage, unchanged reactive re-executions and provider billing overhead; a conflicting CAS guard's submitted payload need not equal the current stored value. These are disclosed application-level storage-traffic measurements, not provider-billed database bytes. No plan/team/project changes or customer-record access.

Design: bounded server-side Convex subscriptions push changed checkpoints, inputs and capability revocations to each HTTP invocation. A private incremental simulation produces fog-filtered frames every 60 ms; it never sends a checkpoint/log or enemy fog information to the browser. Authority/event processing runs on each pushed update and at 500 ms intervals between updates. Time-only checkpoints and subscribed human presence are saved every ten seconds; inputs, new event cursors and final reports still commit immediately through atomic CAS. The simulation itself and persisted input log are unchanged.

A detected disconnect invalidates the invocation even if the SDK reconnects quickly. Earliest document expiry and a five-second authority lease force a nonce-bearing fresh read rather than extending capability lifetime or trusting the SDK's longer half-open-socket watchdog. A live expiry regression exposed a cached revalidation result; the nonce repair reduced fixture stream closure to 485 ms and closed its only subscription. Subscribed mutations use the same ordered connection: the actual-cloud regression confirmed query state updates before mutation completion, avoiding CAS against a pre-write snapshot.

Connections close on response completion/disconnect. Agent event waiting keeps its original 500 ms cadence without repeatedly querying storage. Idle lobby polling is five seconds (queue one, rooms two). Account-cookie validation is not replaced with a cross-request cache. The REST fallback retains its one-second checkpoint and five-second presence semantics; its stream projects locally between bounded refreshes.

The first polling-only candidate sustained 13.67/14.26 FPS but still used 2,292 calls: it did not meet the fivefold target. It was not deployed/promoted. The reactive candidate replaces those residual stream/event polling reads rather than accepting a weaker threshold.

## Reproduced findings and fixes

The first cloud run completed an MCP match but delivered only 8.82/7.44 fps. A later 80-swarm run ended before both streams reached 40 frames, and an agent poll exhausted checkpoint CAS retries. Every-frame competing checkpoint writes were the cause. The final adapter reads bearer/session/checkpoint in one consistent Convex query, projects deterministic subsecond frames read-only, and persists a checkpoint when it is at least one second behind. Inputs, refreshes and results still commit atomically; all read-only records must belong to the same fresh snapshot. Fresh report-log reads bypass speculative caches. Final live capacity and MCP tests pass above 10 fps.

Cloud browser diagnostics found a finished, report-bearing match whose UI had stopped receiving frames. An initial HTTP 503 permanently closes EventSource; the prior label claimed reconnecting without reopening it. A regression test failed with exactly one stream attempt, then passed after adding an explicit same-match retry for permanently closed streams. Stale callbacks and reconnects after leaving/final report are ignored.

Permanent aggregate Elo could exceed Convex's 1 MiB document limit. It is now one record per identity plus an indexed, bounded top-twelve projection; the game overlays at most two pending changes and returns the exact top ten. Tests cover over 1 MiB of aggregate ratings, rating drops and indexed-board CAS without oversized records.

No database was reset or deleted. `sim.js` and offline `server.js` are unchanged from baseline. Deleted `scripts/test-redis.js`; replaced it with `scripts/test-convex.js`. The old durable adapter/Lua and provider references were removed, not retained as compatibility code. Generated bindings, build outputs, dependency caches, credentials and traces remain ignored.
